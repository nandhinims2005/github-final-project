# Simple Interest Calculator

This project is a simple interest calculator. It accepts a principal amount,
an annual rate of interest, and a time period in years, then calculates the
interest using the formula:

```text
simple interest = principal × rate × time / 100
```

Run the Bash calculator with:

```bash
bash simple-interest.sh
```

The script prompts for the principal, rate of interest, and time period, and
prints the calculated simple interest.
